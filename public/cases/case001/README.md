# Optional artwork

The interface includes original SVG dossier portraits and evidence illustrations.
To replace a portrait, add `brian.webp`, `emily.webp`, `tyler.webp`, `luke.webp`,
`anna.webp`, `noah.webp`, `sophie.webp`, `elena.webp`, `maya.webp`, or `oliver.webp` here and restart the dev server or rebuild.
The portrait loader discovers local assets at build time; no external image API is used.
